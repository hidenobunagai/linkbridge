LinkBridge

ストックダイヤラーからの発信を楽天リンクに転送する

個人用 Android アプリ

最新版をダウンロード

バージョン 1.1-shizuku（APK / 約 11MB）

できること

「デフォルト通話転送アプリ」に設定すると、ダイヤラーからの発信を楽天リンクのダイヤラーへ引き継ぎます。緊急通報やショートコード等の特別な番号は通常発信のまま通し、実際に発信された通話だけを通話履歴に残します。

インストール方法

  1. 上のボタンで APK をダウンロードし、通知またはファイルアプリから開く。初回は「提供元不明のアプリ」のインストール許可が必要です。
  2. アプリを開き「デフォルト通話転送アプリに設定」から LinkBridge を選択。
  3. 次を許可します: 通話履歴への書き込み（WRITE_CALL_LOG）、画面の上に表示（SYSTEM_ALERT_WINDOW）、通知へのアクセス。一部の権限は設定で付与できない場合があり、その場合は adb から付与してください。

詳しい手順は README を参照してください。
