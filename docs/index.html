ANDROID アプリ

LinkBridge

ストックダイヤラーからの発信を 楽天リンク に転送する

個人用アプリ

最新版をダウンロード

バージョン 1.1-shizuku ・ APK（約 11MB）

ワンタップ転送

ダイヤラーからの発信を、そのまま楽天リンクのダイヤラーへ引き継ぎます。

賢い番号判定

ショートコードや緊急通報など特別な番号だけを通常発信のまま通します。

履歴も自動補完

実際に発信した通話だけを通話履歴に残します。発信していない誤検知なし。

インストール方法

  1. 上のボタンで APK をダウンロードし、通知またはファイルアプリから開く。初回は「提供元不明のアプリ」のインストール許可が必要です。
  2. アプリを開き「デフォルト通話転送アプリに設定」から LinkBridge を選択。
  3. 通話履歴の書き込み・画面の上に表示・通知アクセスの権限を許可します。一部の端末では設定画面で付与できない場合があるため、その際は adb から付与してください。

詳しい手順は README を参照してください。
